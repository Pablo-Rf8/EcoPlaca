01 · Tu cuenta

Acceso, registro y sesión

Crear una cuenta

  1. Pulsa Registro en la navegación.
  2. Escribe nombre completo (2 a 150 caracteres) y un correo válido (hasta 150).
  3. Introduce una contraseña de al menos 8 caracteres. El máximo es 72 bytes UTF-8; acentos y emojis pueden ocupar varios bytes.
  4. Selecciona Donante para publicar hardware o Técnico para solicitarlo y recibirlo.
  5. Pulsa Crear cuenta. Mientras se envía aparece “Registrando…” y el botón queda deshabilitado.
  6. Si funciona, volverás a Iniciar sesión con un aviso de registro completado.

Iniciar sesión

  1. Pulsa Iniciar sesión, escribe correo y contraseña y confirma.
  2. Usa Mostrar / Ocultar si necesitas revisar la contraseña.
  3. Al entrar se muestra tu nombre y rol. Si abriste una pantalla protegida antes del login, la aplicación intenta volver a ella.

Cerrar sesión

Pulsa Cerrar sesión. Se limpia la sesión del navegador y se abre el login. Al vencer la sesión, inicia sesión nuevamente. El cierre o cambio de sesión en otra pestaña también se refleja en la aplicación.

ADMIN

La cuenta de administrador no se ofrece en Registro. La prepara el responsable técnico mediante el seed. Este documento no publica contraseñas reales.

Problemas de acceso

Revisa correo y contraseña. Si la cuenta está inactiva o no puedes entrar, contacta al responsable. No hay una pantalla de recuperación de contraseña implementada.

02 · Inventario

Buscar en el catálogo

El Catálogo es público. Cada tarjeta muestra título, código de trazabilidad, categoría, condición, peso, CO₂ potencial, notas y centro cuando están disponibles.

Combinar filtros

  1. Escribe título, marca o código en Buscar. La búsqueda espera unos 350 ms después de dejar de escribir.
  2. Selecciona un Estado y una Condición. Los filtros se combinan.
  3. Revisa el contador y las tarjetas. Pulsa Limpiar filtros para consultar todo el inventario.
EstadoQué indica
DisponiblePuede solicitarse si cumple las condiciones de reserva.
ReservadoHay una transferencia en curso; no se puede reservar de nuevo.
EntregadoLa recepción física fue confirmada.
Asignado / RecicladoEstados adicionales del inventario; no son una nueva disponibilidad.
Condición visibleSignificado
OperativoHardware identificado como funcional.
RepuestosHardware reparable; valor interno REPARABLE.
ChatarraDesguace o reciclaje; DESGUACE_RECICLAJE.
Carga, vacío y error

“Cargando dispositivos…” indica una consulta. Si no hay resultados, cambia los filtros. Ante un error pulsa Reintentar; el catálogo no presenta dispositivos ficticios para ocultarlo.

CO₂ potencial

El valor de una tarjeta es una estimación. Publicar o reservar hardware todavía no añade su peso al total recuperado del Dashboard.

03 · Donante / ADMIN

Publicar hardware

Inicia sesión como Donante o ADMIN y abre Publicar hardware. Categorías y centros se cargan desde la base de datos.

CampoCómo completarlo
Título *De 3 a 150 caracteres. Ejemplo: “Placa madre para reparación”.
Categoría *Selecciona la categoría del dispositivo.
Centro de origen *Debe estar activo y admitir la categoría. Al cambiar categoría, selecciona el centro de nuevo.
Marca, modelo y serieOpcionales; hasta 100 caracteres por campo.
Estado funcional *Operativo, Reparable o Desguace / reciclaje.
Peso en kg *Mayor a 0, máximo 9999.99 y hasta dos decimales; por ejemplo, 1.25.
Notas / especificacionesOpcionales, hasta 5000 caracteres; indica fallas, accesorios y datos técnicos.

Enviar

  1. Comprueba los campos marcados con *. Corrige los errores indicados bajo cada campo.
  2. Pulsa Publicar hardware una vez y espera mientras aparece “Publicando…”.
  3. Tras el éxito se muestra un aviso y vuelves al catálogo.
  4. Busca el hardware y comprueba que está Disponible.
No hay centros compatibles

Elige otra categoría solo si corresponde al hardware, o solicita al administrador un centro activo compatible. No cambies a una categoría incorrecta para evitar la validación.

Autor de la publicación

La aplicación usa la cuenta autenticada como donante. No hay un selector para publicar a nombre de otra persona.

04 · Técnico

Solicitar una reserva

La reserva está disponible para TECHNICIAN. ADMIN puede confirmar entregas, pero no solicitar una reserva mediante esta acción.

01BuscarCatálogo
02SolicitarDiálogo
03ConfirmarMotivo
04ReservadoOrden pendiente
  1. Entra como Técnico y busca hardware Disponible.
  2. Pulsa Solicitar para Reparación en su tarjeta.
  3. Escribe un motivo de 1 a 255 caracteres; no dejes solo espacios.
  4. Pulsa Confirmar solicitud o Cancelar para volver sin enviar.
  5. Espera el resultado; los botones se bloquean mientras se guarda.
  6. Si funciona, el dispositivo pasa a Reservado y se crea una orden Pendiente. Abre Mis transferencias.
La tarjeta desapareció

Si filtrabas por Disponible, el dispositivo reservado deja de cumplir ese filtro. Selecciona Reservado o limpia filtros para encontrarlo.

Conflicto de reserva

Otro técnico pudo reservarlo antes. La API rechaza tu petición y actualiza el catálogo. Elige otro dispositivo; el aviso no significa que tu reserva haya tenido éxito.

Coordinar la recogida

Acuerda lugar y horario con el responsable del centro por el canal habitual. La aplicación no incluye chat ni agenda de recogidas.

Cancelar después de reservar

Puedes cancelar el diálogo antes de enviar. El panel actual no ofrece cancelar una orden ya creada; solicita al administrador la revisión del caso.

05 · Técnico / ADMIN

Confirmar la entrega física

Abre Mis transferencias. El Técnico ve sus órdenes y ADMIN puede ver todas. Se muestran las activas: Pendientes o En tránsito.

Antes de confirmar

  • Comprueba título y código de trazabilidad contra el hardware recibido.
  • Revisa número de orden, técnico, origen, destino, fecha y motivo.
  • Verifica que hubo entrega física. Una reserva no equivale a una recepción.

Registrar recepción

  1. Pulsa Confirmar recepción física.
  2. Lee la advertencia: no se puede revertir desde este panel.
  3. Pulsa Cancelar si aún no recibiste el equipo.
  4. Si ya lo recibiste, pulsa Sí, recibí el hardware.
  5. Espera el aviso de éxito: la orden pasa a COMPLETADA y el dispositivo a ENTREGADO.
  6. La orden sale de las activas. Busca el dispositivo Entregado en el Catálogo y consulta Dashboard.
Acción irreversible desde el panel

No confirmes para avanzar el proceso sin recibir el equipo. Si se confirmó por error, contacta al administrador para revisar el registro; no existe un botón Deshacer.

Orden modificada por otra persona

Si aparece un conflicto, cierra el diálogo y pulsa Actualizar. Comprueba si otro usuario autorizado completó la orden. Repetir la confirmación no debe duplicar impacto.

06 · Roles autenticados

Consultar impacto ambiental

Abre Dashboard tras iniciar sesión. Tres tarjetas muestran información real de la base de datos.

TarjetaInterpretación
RAEE rescatado (kg)Peso de hardware Entregado o Reciclado. No incluye publicaciones nuevas ni reservas pendientes.
CO₂ equivalente evitado (kg)Estimación acumulada del hardware recuperado según peso y factor de categoría.
Transferencias activas y completadasPendiente + En tránsito + Completada. También se muestra el desglose de activas y completadas.

Actualizar resultados

  1. Revisa la hora de Última actualización.
  2. Pulsa Actualizar métricas para consultar en ese momento.
  3. La vista consulta cada 30 segundos mientras está abierta.
  4. Si otra persona acaba de confirmar una entrega, actualiza o espera la próxima consulta.
Ejemplo ilustrativo

Una placa de 1.25 kg con factor 35.50 kg CO₂/kg tiene un impacto estimado de 44.38 kg CO₂. Al confirmar la entrega aumenta el peso recuperado en 1.25 kg y se suma esa estimación. El valor depende del factor configurado.

Error de actualización

Puede mantenerse el último resultado válido junto con un aviso. No lo interpretes como una consulta nueva exitosa. Actualiza cuando vuelva la conexión.

Significado ambiental

El CO₂ es una estimación para visualizar la recuperación del hardware. No constituye por sí solo una certificación ni un comprobante de reciclaje. ADMIN puede actualizar el factor de categoría.

07 · ADMIN

Funciones del administrador

ADMIN se prepara por configuración técnica. En la navegación tiene Publicar hardware, Mis transferencias, Dashboard y Comentarios y notas.

FunciónCómo se realiza
PublicarFormulario de publicación; la cuenta ADMIN figura como donante.
Supervisar entregasMis transferencias muestra órdenes de todos los técnicos. Confirmar solo recepciones verificadas.
Consultar impactoDashboard, con actualización manual o periódica.
Categorías / centrosGestión por API con token ADMIN; no hay panel visual de esos CRUD.
Editar / retirar hardwarePor API, conforme a disponibilidad, propiedad e historial.

Cambios de categorías y centros

Para agregar una categoría, habilitar un centro o cambiar un factor ambiental, utiliza los endpoints descritos en la Documentación del proyecto y backend/api.http. Solo una cuenta autorizada puede hacer esas escrituras.

Conservación

Desactivar un centro conserva sus datos e historial. Una categoría vinculada a dispositivos o centros no se elimina; la API devuelve un conflicto.

Comentarios y notas

La vista está disponible para Técnico y ADMIN. Sus comentarios son locales y se pierden al salir o recargar. Las notas del formulario de publicación sí se guardan en MySQL como parte del dispositivo.

Accesos individuales

Usa una cuenta individual. Cierra sesión en equipos compartidos y no compartas contraseña ni token.

Problemas frecuentes

SituaciónQué hacer
No aparece Publicar hardwareEntrar como Donante o ADMIN.
No aparece Solicitar para ReparaciónEntrar como Técnico y buscar hardware Disponible.
Correo ya registradoUsar la cuenta existente o un correo distinto que te pertenezca.
Credenciales incorrectasRevisar correo y contraseña; Mostrar permite comprobarla.
Se pide login otra vezLa sesión pudo vencer o cambiar en otra pestaña; iniciar sesión nuevamente.
No hay resultadosLimpiar filtros o cambiar estado/condición y búsqueda.
No hay centro compatiblePedir al administrador un centro activo para esa categoría.
Reserva rechazadaOtro técnico pudo reservarlo. Actualizar y elegir hardware disponible.
No hay órdenes activasRevisar cuenta; las completadas dejan de aparecer en ese listado.
No aumenta el pesoDebe haber entrega confirmada; actualizar Dashboard.
API no disponibleComprobar conexión y avisar al responsable técnico; no reenviar repetidamente.
Página no encontrada o acceso denegadoVolver al Catálogo; revisar dirección y permisos del rol.

Información para soporte

  • Fecha y hora, pantalla y acción realizada.
  • Texto del aviso, código de dispositivo y número de orden.
  • Rol de la cuenta. Nunca enviar contraseña ni token.

09 · De principio a fin

Recorrido completo

Usa un dispositivo nuevo para verificar el ciclo. En una evaluación, distingue los datos sintéticos de una recepción real.

PasoCuenta / acciónResultado
1Donante: entrar y publicar con peso y centro compatibles.Disponible en el Catálogo.
2Donante: anotar código y cerrar sesión.Hardware identificado para coordinar la entrega.
3Técnico: buscar y pulsar Solicitar para Reparación.Diálogo con motivo.
4Técnico: confirmar solicitud.Reservado y orden Pendiente.
5Técnico: abrir Mis transferencias.Coinciden código, título, centro y motivo.
6Centro y Técnico: entregar físicamente el equipo.Hardware recibido y comprobado.
7Técnico: confirmar Sí, recibí el hardware.Completada / Entregado.
8Técnico: abrir Dashboard y actualizar.Aumentan kg y CO₂; cambia el conteo de órdenes.
Sin duplicaciones

El backend evita dos reservas simultáneas exitosas y rechaza completar otra vez la misma orden. Una operación rechazada no suma impacto.

Comprobación final

  • El catálogo filtrado por Entregado permite encontrar el dispositivo.
  • La orden sale de las activas.
  • El Dashboard incorpora datos confirmados, no solo el acto de publicar.
