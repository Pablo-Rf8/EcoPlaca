# EcoPlaca
EcoPlaca es una plataforma web en Angular para la gestión circular y trazabilidad de residuos electrónicos (RAEE). Conecta a donantes de hardware en desuso con talleres técnicos y centros de reciclaje para catalogar piezas, gestionar reservas y medir en tiempo real el impacto ambiental de componentes rescatados de vertederos
